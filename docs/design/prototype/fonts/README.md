# Preview fonts

These are local copies of the Latin font faces served by Google Fonts for
DM Sans (400–700), Instrument Serif (regular/italic) and Geist Mono (400–500).
`fonts.css` maps each file to its family, weight and style.

Source: Google Fonts CSS API and its `fonts.gstatic.com` assets. The corresponding
SIL Open Font License files are retained here for each family, from
`google/fonts/ofl/{dmsans,instrumentserif,geistmono}/OFL.txt`.

Keeping preview fonts local makes screenshot review independent of a third-party
font request and avoids silently changing typography during review.
